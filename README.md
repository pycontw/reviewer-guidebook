# PyCon TW 2026 Reviewer Guide 審稿指南

(English below)

您好，歡迎您加入 PyCon TW 2026 審稿的行列。請點選 [審稿指南](reviewer-guide.md) 開始了解審稿流程。

本次審稿的表定時程如下：
+ June 1: Call for Proposals 截止
+ June 2 ~ June 15: 第一階段審稿
+ June 22 ~ July 6: 投稿者修稿階段
+ July 7 ~ July 20: 第二階段審稿
+ August 2: 完成入選、備取、拒絕稿件清單

Hi, welcome to PyCon TW 2026 proposals review.  Please visit [Proposal Review Process](reviewer-guide.en.md) to read the detailed description of the review process.

Our schedule is as follows:
+ June 1: End of Call for Proposals
+ June 2 ~ June 15: First round review
+ June 22 ~ July 6: Modification stage for submitters
+ July 7 ~ July 20: Second round review
+ August 2: Announce accepted and rejected proposals, and waiting list
